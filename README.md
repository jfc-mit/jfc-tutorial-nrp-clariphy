## Using the deck

Open the page; the tutorial cut is the default. `→` / click advance, `←` back, `O` overview, `T` pauses the terminal replay, `?` help.
The deck is a single `index.html` with no build step; `?profile=none` shows every scene of the parent talk,
`?theme=dark|light|auto` overrides the theme, `#scene-id` jumps to a scene.

This is a cut of the JFC talk deck, [jfc-mit/jfc-talk](https://github.com/jfc-mit/jfc-talk)
(branch `clariphy-tutorial-2026-09-14`).
